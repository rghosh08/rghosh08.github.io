nvidia-nvswitch-setup
Debian package · v0.1.0

Idempotent installer for headless multi-GPU NVSwitch systems on stock Ubuntu. It selects a matched NVIDIA server-open driver and Fabric Manager branch, verifies the DKMS module build for the running kernel, and starts Fabric Manager so the NVSwitch fabric initializes correctly.

sudo apt-get install -y ./nvidia-nvswitch-setup_0.1.0_all.deb

prompt-injection-defense
Python · MIT · v0.10.5

Lightweight, rule-based prompt injection detector for LLM applications, aligned with the OWASP Top 10:2025. Detects attempts to hijack LLM behavior across all ten vulnerability categories — prompt injection, jailbreaks, SQL/command/template injection, access-control bypass, credential extraction, log evasion, and obfuscation techniques such as leet-speak, emoji, and character spacing.

pip install prompt-injection-defense
